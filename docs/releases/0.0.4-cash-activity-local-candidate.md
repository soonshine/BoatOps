# BoatOps 0.0.4 Gate B — local cash activity candidate

状态：`LOCAL_WORKTREE / NOT_DEPLOYED / NOT_RELEASED`

## 范围

本候选只增强本地、虚构、fail-closed 的 `/demo` 页面。每个当前组织范围内的 `ACTIVE` demo cash account 显示组织时区今日摘要，以及截至下一个本地午夜向前 7 个本地营业日的最多 200 条现金活动。活动保持正式 read API 的发生时间/ID顺序，并显示本地时间、方向、posting kind、金额/币种、状态、来源和冲销关系。

现金活动是燃油、费用、库存 `PURCHASE` 及冲销命令的派生只读结果。页面不允许手工现金记账，不新增写路由，不直接写 `cash_postings`；demo 命令仍由现有 `OperationsCostController` 正式 controller/service 路径执行。`LOAD / CONSUME / RETURN / WASTE` 和非现金库存冲销不会产生现金行。
