## 已交付

- Bearer API Client 认证；组织身份只来自认证上下文。

- 纯虚构、可重复执行的本地 Demo Seeder；Token 只接受环境变量，库内仅存 SHA-256 hash。
- 本地审核首页和静态 API 文档。

## 本地运行

在 Git Bash 中执行；不要把生成的 Token 提交到 Git：

```bash
cd /e/ayany/BoatOps
openssl rand -hex -out .tools/demo-token 24
TOKEN=$(tr -d '\r\n' < .tools/demo-token)
PHP='/c/Users/caosh/AppData/Local/Microsoft/WinGet/Packages/PHP.PHP.8.4_Microsoft.Winget.Source_8wekyb3d8bbwe/php.exe'
BOATOPS_DEMO_TOKEN="$TOKEN" \
DB_CONNECTION=sqlite \
DB_DATABASE='E:\ayany\BoatOps\.tools\demo.sqlite' \
PHPRC='E:\ayany\BoatOps\.tools' \
"$PHP" artisan migrate:fresh --seed --force

cd public
DB_CONNECTION=sqlite \
DB_DATABASE='E:\ayany\BoatOps\.tools\demo.sqlite' \
PHPRC='E:\ayany\BoatOps\.tools' \
"$PHP" -S 127.0.0.1:8092 index.php
```

- 首页：`http://127.0.0.1:8092/`
