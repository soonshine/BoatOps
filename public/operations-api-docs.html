BoatOps Internal Operations API (1.0.0-alpha.5)

Download OpenAPI specification:

Private operations commands and operator schedule catalog/calendar reads.

Private alpha contract. Inventory and trip commands require operations.write. Finance writes require operations.finance.write, and finance reads require operations.finance.read or operations.finance.write. Schedule reads require operations.schedule.read or operations.schedule.write; schedule writes require operations.schedule.write. Schedule catalog writes use canonical server-owned identities and audit logs. This API is not part of the channel-facing Inventory Provider API and must not be exposed to untrusted channel clients.
